How the Harness Works

Pick something you might say to Claude. The diagram walks through what happens, step by step: what Claude already has loaded, which checklist it pulls in, and what the safety guards do before any command runs.

You say…

You don't name checklistsDescribe what's happening. Claude matches your words against the one-line index and loads the checklist that fits.
Guards don't rely on memoryThey are scripts that check every command before it runs. Claude can't forget them, and it reports a block instead of working around it.
Small by designOnly the rules and the index load every session, about 2,420 tokens. A checklist costs nothing until it matches.
Install in Claude Code: /plugin marketplace add rmusayevr/claude-harness then /plugin install harness@harness. New to it? Type /harness:start. Source: github.com/rmusayevr/claude-harness
